# 需求

- Word 上标内容必须保留并输出为 HTML `sup`，上标后的普通正文也不能丢失。
- Ruby/EQ 域的结果抑制必须严格限制在对应字段范围内，不得吞掉字段之后的文字。
- 识别 Word run 的字号属性并在 HTML 中保留字号。
- 保持上一轮右对齐、域内 Ruby、普通域和嵌套链接行为不回退。

# 验收标准

- 普通 `w:vertAlign w:val="superscript"` 输出 `<sup>`，相邻和后续文本完整。
- Ruby 域结束后的上标及普通文本均完整输出。
- `w:sz` 和仅有 `w:szCs` 的 run 可转换为对应 pt 字号。
- `styles.xml` 中的默认字号、段落样式字号和字符样式字号（含 `basedOn` 继承）可以生效。
- 自动化测试和 DOCX 包端到端转换通过。
