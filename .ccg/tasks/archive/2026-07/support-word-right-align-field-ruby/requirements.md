# 需求

增强 DOCX 到 HTML/EPUB 的转换能力：

- 识别 Word 段落的右对齐，并在输出 HTML 中保留该对齐语义。
- 识别写在 Word “域”结构中的 Ruby（拼音/注音），并输出正确的 HTML Ruby 标记。
- 保持现有普通文本、样式、链接及其他复杂域的转换行为不回退。

# 验收标准

- 右对齐段落输出可由 HTML/CSS 表达的 `text-align: right`。
- 域代码形式的 Ruby 能输出包含 `ruby`、`rt` 的 HTML，基字与注音内容正确。
- 新增自动化测试覆盖上述两种场景及关键兼容分支。
- 项目现有测试（如有）与新增测试全部通过。
